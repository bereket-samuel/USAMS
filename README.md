# University Staff Attendance System

##  Project Overview

The **University Staff Attendance System** is a Java-based application developed to help manage and record university staff attendance.

The project was developed as a university Computer Science project and focuses on applying programming concepts to a practical attendance management problem.

##  Objectives

* Manage university staff information.
* Record staff attendance.
* View and manage attendance records.
* Reduce manual attendance management.
* Provide an organized way to handle staff attendance information.

##  Main Features

* Staff information management
* Staff attendance management
* Attendance record handling
* User interaction through the application
* Data storage and retrieval

##  Technology

* **Java**
